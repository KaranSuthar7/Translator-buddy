MY TRANSLATOR - SIMPLE PYTHON + HTML PROJECT

1. Open CMD in this project folder.

2. Install required packages:
   python -m pip install -r requirements.txt

3. Run:
   python app.py

4. Open in browser:
   http://127.0.0.1:5000

Project structure:
translator/
|-- app.py
|-- requirements.txt
|-- README.txt
|-- templates/
|   |-- index.html
|-- static/
    |-- style.css
